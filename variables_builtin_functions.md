# Built-in Functions

Python comes with a bunch of **built-in functions** that are ready to use right out of the box. 🚀 That means you don't need to install anything or import extra libraries—they're already there, waiting for you.

Think of built-in functions as Python's **superpowers**. Instead of writing everything from scratch, you can simply call these functions and let Python do the hard work.

Some of the most commonly used built-in functions are:

* `print()` – Display output on the screen.
* `len()` – Find the length of a string, list, or other object.
* `type()` – Check the data type of a value.
* `int()` – Convert a value to an integer.
* `float()` – Convert a value to a floating-point number.
* `str()` – Convert a value to a string.
* `input()` – Take input from the user.
* `list()` – Create or convert to a list.
* `dict()` – Create a dictionary.
* `min()` – Find the smallest value.
* `max()` – Find the largest value.
* `sum()` – Add up all the values in an iterable.
* `sorted()` – Sort items in ascending order.
* `open()` – Open a file.
* `help()` – Learn more about a function or object.
* `dir()` – Show the available attributes and methods of an object.

Don't worry if this list feels a bit overwhelming. 😅 Nobody memorizes all these functions on Day 1. As you keep coding, you'll naturally start using them over and over again until they become second nature.

## `help()` and `dir()`

Python also has some awesome functions that help you learn Python itself.

* `help()` shows documentation and explains how a function or object works.
* `dir()` lists the available methods and attributes of an object.

These are like your built-in cheat codes when you forget how something works. 🧠✨

While experimenting, you might also notice that some words have special meanings in Python. These are called **reserved keywords** (like `if`, `for`, `while`, and `class`). Since Python already uses them, you can't use them as variable or function names. We'll learn more about variables in the next section.
